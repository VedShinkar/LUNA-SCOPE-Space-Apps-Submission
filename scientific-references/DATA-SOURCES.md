# Scientific data sources and references

This page records the primary scientific sources identified in the LUNA-SCOPE project workflow. It distinguishes source datasets and reference services from local processing, benchmark fixtures, and validation logic.

## 1. Lunar terrain — NASA LOLA

**Instrument:** Lunar Orbiter Laser Altimeter (LOLA), Lunar Reconnaissance Orbiter (LRO).

**Role in LUNA-SCOPE:** Lunar topography and terrain-derived analysis. The project's locally documented high-resolution terrain bundle is for Site04 (Shackleton region).

- [NASA Planetary Geology Data System — Site04 LOLA 5 m/pixel products](https://pgda.gsfc.nasa.gov/data/LOLA_5mpp/Site04/)
- [NASA PGDA Product 78](https://pgda.gsfc.nasa.gov/products/78)
- [NASA PDS Geosciences Node — LRO archive](https://pds-geosciences.wustl.edu/missions/lro/default.htm)

### Locally documented Site04 files

The project records identify these GeoTIFF products:

- `Site04_final_adj_5mpp_surf.tif`
- `Site04_final_adj_5mpp_ldec.tif`
- `Site04_final_adj_5mpp_slp.tif`
- `Site04_final_adj_5mpp_slperr.tif`
- `Site04_final_adj_5mpp_toterr.tif`

The inspected rasters are documented as 3,200 × 3,200 pixels, 5 m/pixel, with Float32 values (10,240,000 pixels). Check the source product metadata and project terrain guide for band meaning, units, and processing conventions before interpreting individual layers.

## 2. Celestial reference and ephemeris

### NASA/JPL Horizons

- [JPL Horizons System](https://ssd.jpl.nasa.gov/horizons/)

Horizons is used as an external ephemeris reference/comparison service in the project's validation tooling. The existence of a benchmark catalogue or passing offline comparison tests does not establish that a live data capture has been performed.

## Provenance policy

For reproducible scientific claims, record the dataset product identifier, source URL, retrieval date, file checksum, coordinate reference system, units, processing steps, kernel versions, time system, reference frame, and software version/commit. Clearly distinguish:

1. NASA/JPL source observations or reference products.
2. Locally processed products derived from those sources.
3. Synthetic fixtures used for tests and demonstrations.
4. Modelled or simulated outputs generated by LUNA-SCOPE.

Do not label synthetic data, locally generated values, or unverified outputs as direct NASA measurements.
