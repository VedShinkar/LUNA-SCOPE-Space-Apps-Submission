## Deck summary

The 7-page deck introduces LUNA-SCOPE and Team VayuTej, frames the four interacting site-selection considerations (terrain, solar access, Earth communication, and mission feasibility), describes the five-step product workflow, presents terrain-analysis capabilities, explains solar and Earth-visibility considerations, summarizes mission intelligence and the deterministic Copilot concept, and closes with impact, references, and future directions.

See the main README for the [published demonstration video](https://youtu.be/1WInFyLfS4M).
